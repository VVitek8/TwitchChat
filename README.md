# TwitchChat

Displays Twitch chat messages in the PEAK in-game chat. Messages appear with the `[Twitch]` prefix. Fork of PeakTextChat

## Configuration

1. Install the mod and run the game once to generate the config file.
2. Open `BepInEx/config/V8.TwitchChat.cfg`.
3. Fill in the `[Twitch]` section:

```ini
[Twitch]
Username = your_username
OAuthToken = oauth:your_token (optional)
