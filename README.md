# TwitchChat

Displays Twitch chat messages in the PEAK in-game chat. Messages appear with the `[Twitch]` prefix. Fork of PeakTextChat

## Configuration

Open `BepInEx/config/com.borealityy.peaktextchat.cfg` and fill in the `[Twitch]` section:

```ini
[Twitch]
Username = your_nickname
OAuthToken = oauth:your_token
